# Career Compass

A Full Stack Career Guidance Platform built using Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

- User Registration & Login
- Personalized Learning Roadmaps
- Progress Tracking Dashboard
- Responsive UI
- MySQL Database Integration

## Tech Stack

- Java 17
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript

## Future Scope

- AI-powered Roadmap Generation
- Resume Analysis
- Interview Preparation
- Skill Gap Analysis
